# Ντετέκτιβ Δεδομένων

Παιχνίδι-εργαστήριο περιγραφικής στατιστικής για τη Β΄ Γυμνασίου, για το μάθημα CS148 «Ανάπτυξη Ψηφιακού Υλικού και Διδακτικών Σεναρίων με ΤΠΕ» (Τμήμα Πληροφορικής, Πανεπιστήμιο Δυτικής Μακεδονίας).

**▶ Παίξτε online:** https://michadasis.github.io/ntetektiv-dedomenon/

- Πέντε αποστολές: πίνακας συχνοτήτων, μέτρα θέσης, ομαδοποιημένα δεδομένα, ιστόγραμμα και εκατοστιαία σημεία, διασπορά.
- Εργαστήριο δεδομένων με τις αντίστοιχες συναρτήσεις υπολογιστικού φύλλου και εκτέλεση βήμα-βήμα του αλγορίθμου σε ψευδοκώδικα, τελικό κουίζ και αναφορά προόδου.
- Ένα αυτόνομο αρχείο HTML/CSS/JavaScript χωρίς εξωτερικές βιβλιοθήκες. Λειτουργεί και offline: κατεβάστε το `index.html` και ανοίξτε το με διπλό κλικ.
- Τα σύνολα δεδομένων των αποστολών είναι ενδεικτικά διδακτικά παραδείγματα.
